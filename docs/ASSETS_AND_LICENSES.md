## What is in this repository (publishable)
| Path | What | Licence |
|---|---|---|
| `data/demo_library/` | 22 **procedurally generated** dental arches (`backend/build_demo_library.py`, `dental_reg/procedural.py`) + `catalogue.json` | Original work of this project. Not anatomical. |

No patient photographs, credentials or API keys are committed. `.env` and `private_data/` are git-ignored.

## What is deliberately NOT in the publishable tree
**Teeth3DS** (the source of Person 2's meshes) is licensed **CC BY-NC-ND 4.0** (non-commercial research/education only; **no
derivatives**; commercial use needs a separate licence from the dataset owners). Source checked on the dataset project page
(<https://github.com/abenhamadou/3DTeethSeg22_challenge>, accessed 2026-10). Consequences:
- Decimated/re-packaged models (my earlier `data/library/*.npz`), per-tooth copies in `data/samples/`, and images rendered from them are
  derivatives, so they are kept out of the publishable tree (moved to git-ignored `private_data/`).
- Use a real library locally with `DENTAL_LIBRARY_DIR=/path/to/library` (build one with `backend/build_library.py` from your own
  licensed download). Do not deploy or publish it unless you hold a licence that permits it.
- **Person 2's repository (`processed_part1_*`, 300 cases) already publishes per-tooth extractions of Teeth3DS scans.** Whether that
  complies with the ND clause is for the repository owner to decide; this project does not rely on or copy those files.
- Commit `97034e0` (local, never pushed) still contains the earlier derived files in its history. Publish the clean branch instead
  (see README "Publishing"), not that commit.
- This is not legal advice; confirm with the dataset owners if you intend to publish or commercialise.
